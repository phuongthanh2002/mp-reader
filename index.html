MicroProfiler Reader

Mở file dump microprofile-*.x.html (nút Dump trong MicroProfiler, Ctrl+F6). File được đọc ngay trên máy bạn, không tải lên đâu.

Kéo thả file dump vào trang, hoặc bấm "Mở dump".

Thả file dump vào đây để bắt đầu

  1. Trong Roblox (Client hoặc Studio) bấm Ctrl+F6 để mở MicroProfiler.
  2. Đứng ở chỗ muốn đo vài giây, rồi bấm Dump trên thanh menu của MicroProfiler.
  3. File được lưu ở %LOCALAPPDATA%\Roblox\logs\microprofile-*.x.html. Kéo nó vào trang này, hoặc bấm nút bên dưới.

Muốn so sánh trước/sau: mở dump thứ nhất, rồi bấm "Mở dump để so sánh" cho dump thứ hai (hoặc kéo cả hai file vào cùng lúc).

Phát hiện

Những gì app tự nhận ra trong dump, kèm gợi ý xử lý.

    Tổng quan frame

    ms ms

    Ngân sách frame của RBX Main

    Một frame trung bình của luồng Main chia theo nhóm việc, so với mục tiêu trung bình. Phần gạch đỏ là vượt mục tiêu.

    Thời gian từng frame

    Mỗi cột là một frame, chia màu theo nhóm việc trên Main; phần nhạt là lúc Main rảnh. Bấm vào cột để xem riêng frame đó (phím ← → để chuyển, Esc để bỏ chọn).

    Các luồng

    Thời gian bận mỗi frame, đã trừ lúc ngủ (Sleep). Luồng nào gần bằng thời gian frame là luồng đang giữ chân FPS, thường là RBX Main.

    Scope tốn thời gian

    Self = thời gian của riêng scope đó. Gồm con = tính cả scope bên trong. Lần/frame = số lần chạy mỗi frame.

    Cây lời gọi

    Scope nào nằm trong scope nào. Bấm để mở/gập. Thanh màu là phần trăm của frame trung bình.

    Dump đã mở gần đây

    Lưu bản tóm tắt trong trình duyệt này để so sánh nhanh. Muốn xem cây lời gọi hoặc từng frame thì mở lại file gốc.

      Từ điển scope

      Giải thích các tên thường gặp. Mục ghi "Phỏng đoán" là rút ra khi đo thực tế, tài liệu Roblox chưa mô tả.
